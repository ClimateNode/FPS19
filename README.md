# Section 19 Report LLM Analysis

## Intro

This repository contains the interim and final outputs of an experimental project undertaken by [Helen Jackson](https://www.linkedin.com/in/helen-jackson-28926285/) (Director of [ClimateNode](https://www.climatenode.org)) for Flooded People using an LLM to extract information on flood impacts from Local Authority Section 19 flood investigation reports. 

It contains:

• a full geoJSON dataset of 10,000+ streets, assets, towns, villages, cities and local authority areas mentioned across approximately 690 reports, and summaries of the information contained about them in those reports.

• interim outputs used to track project progress

The first of these is the current main output: and is contained in [geoJSON/FPS19_full.json.zip](https://github.com/ClimateNode/FPS19/blob/main/geoJSON/FPS19_full.json.zip). It may be updated to include more reports and/or improve extraction technique at a later date. This dataset is also displayed on an interactive map [here](https://www.floodedpeople.org.uk/s19-investigations).

## Disclaimer

These outputs are the result of an experimental *pro bono* project and are available to download and use on an "as is" basis.

LLMs can hallucinate, be over-confident and misunderstand instructions. Use the data with this in mind. If a finding or piece of information in the dataset is materially important to you, *check the corresponding statements in the underlying source*, particularly if it attributes responsibility. Familiarise yourself with the 'Sources of inaccuracy' section and data quality flags in the "[How to interpret the map](https://www.floodedpeople.org.uk/s19-investigations)" section on the interactive map page. The author accepts no responsibility for inaccurate information.
